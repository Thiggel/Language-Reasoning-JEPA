\section{Experimental Design}
\label{sec:experiments}

\paragraph{Domain and interface.}
Stylized iGSM generates arithmetic dependency problems with named quantities, distractor relations, and a target query \citep{igsm2025}. Training instances are generated online. The paper models receive 300,000 examples with shortest solutions ranging from three to nine actions.

At each decision point, the environment supplies a shuffled set of executable intent phrases. It reveals neither the useful action nor the outcomes of unchosen candidates. All learned policies receive the same set and observe the textual consequence of their choice before acting again. The supplied menu is candidate-privileged relative to unrestricted generation. Holding it fixed isolates consequence evaluation from proposal recall and syntax validity.

\paragraph{Models.}
The main JEPA uses 256-dimensional history and action representations and an MLP successor predictor. A second JEPA uses a causal Transformer over encoded history states. The token LM scores candidate phrases by token likelihood. The sentence LM predicts the next intent phrase as a sentence-level target. The sentence-plus-latent model adds next-sentence latent prediction to the sentence objective. Each policy selects from the same current menu.

The main GAR model uses the transition-value factorization from Section~\ref{sec:method}. Objective controls remove ranking, remove pairwise calibration, or remove counterfactual latent prediction. Architecture controls detach GAR gradients from the predictive body, replace the learned energy with raw successor distance, or apply GAR to a direct scorer that bypasses the successor in the policy path. A shuffled-label control retains the candidate sets and counterfactual transitions while destroying their within-state quality correspondence.

\paragraph{Training and selection.}
Every completed learned headline row and primary ablation uses five training seeds. Hyperparameters are selected on validation data. Each model-dataset pair receives its own learning-rate search budget. Ablations reuse the selected rate unless their loss scale or gradient route changes, in which case they receive a local learning-rate check. Test results never select hyperparameters.

\paragraph{Evaluation.}
Strict success requires the shortest possible solution. Success at $+2$ allows at most two excess actions. Each completed seed is evaluated on 200 newly generated episodes. Tables report the mean and sample standard deviation across seed-level success rates. Episodes were not paired across methods, so the current estimates do not support paired model-difference claims.

\paragraph{Diagnostics.}
The local decision audit enumerates the same feasible actions at aligned histories. It records pairwise ranking accuracy, top-1 optimal-action recall, mean regret, rank correlation with exact continuation cost, and the optimal-versus-best-suboptimal margin. Exact continuation cost is an evaluation label and is never available to the policy.

Frozen-feature probes measure operation identity, remaining actions, resolved quantities, and numerical outcomes. Effective rank checks for collapse. The current feature set does not contain controlled paraphrase, negation, operator-swap, or entity-renaming pairs, so no claim about semantic invariance is made.

\paragraph{Scope.}
Only stylized iGSM currently has a complete five-seed headline comparison. Faithful iGSM and non-arithmetic domains remain outside the main claims. Test-time scaling is also excluded. The current evaluator and FLOP accounting do not yet isolate the effect of added inference computation.
