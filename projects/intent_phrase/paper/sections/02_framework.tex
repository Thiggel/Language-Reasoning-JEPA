\section{A framework for latent language planning}
\label{sec:framework}

\subsection{Language actions and consequences}

Let $x$ denote a problem statement, $h_t$ the observed history at step $t$, and $s_t=(x,h_t)$ the corresponding textual state. The environment exposes a finite menu $\mathcal{A}(s_t)$ of executable intent phrases. Executing $a_t\in\mathcal{A}(s_t)$ produces a textual observation $o_{t+1}$ and a new state $s_{t+1}$. An episode succeeds when the requested quantity is resolved. Strict success requires the minimum number of actions. Slack-$k$ success permits at most $k$ excess actions.

The shared menu removes action proposal from the main comparison. It supplies legality at the current state, but not action values, the optimal action, future menus, or a solved state. We use symbolic and future-action information only in labeled diagnostics. Thus the primary question is conditional planning: given identical executable candidates, which training objective creates the most useful decision representation?

\subsection{Joint-embedding prediction}

An online encoder $f_\theta$ maps a textual state to $z_t=f_\theta(s_t)\in\mathbb{R}^d$. An action encoder $g_\theta$ maps an intent phrase to $u_t=g_\theta(a_t)$. A predictor $F_\theta$ produces
\begin{equation}
    \hat z_{t+1}=F_\theta(z_t,u_t).
\end{equation}
The target $\bar z_{t+1}=f_{\bar\theta}(s_{t+1})$ comes from a stopped-gradient exponential-moving-average encoder. The target encoder remains in evaluation mode, and all model dropout is zero. The factual prediction loss is
\begin{equation}
    \mathcal{L}_{\mathrm{pred}}=\lVert\hat z_{t+1}-\operatorname{sg}(\bar z_{t+1})\rVert_1.
\end{equation}
Exact counterfactual transitions supply the same loss for alternative executable actions. These alternatives are generated by the environment and do not use model rollouts.

This objective can learn dynamics without producing the next sentence. It does not impose an action preference. Low prediction error and non-collapsed covariance are therefore necessary diagnostics rather than sufficient planning criteria.

\subsection{Planning geometry as local ordering}

Suppose two feasible actions $a^+$ and $a^-$ have continuation advantages $A_N(s,a^+)>A_N(s,a^-)$. Here $A_N$ measures the consequence of taking $a$ and following a reference continuation for $N$ steps. A planning representation should order their predicted successors accordingly. Let $V_\phi(\hat z_{t+1},z_t)$ be a learned transition-value score. The deployed action score is
\begin{equation}
    Q_{\theta,\phi}(s_t,a)=V_\phi(F_\theta(f_\theta(s_t),g_\theta(a)),f_\theta(s_t)).
\end{equation}
The predictive successor is therefore an explicit decision bottleneck. We assess local planning geometry through pairwise ranking accuracy, top-1 optimal-action recall, action regret, rank correlation with exact continuation advantage, and the positive-versus-best-negative margin. These quantities make a narrower and more testable claim than global cluster quality.

\subsection{Why test-time simulation might help}

The factorization permits recursive simulation. A depth-$D$ planner applies $F_\theta$ along candidate action sequences and selects the first action from the best sequence. If prediction error remains controlled and the value score transfers to imagined states, deeper search can improve decisions without adding parameters. If errors compound or the scorer is calibrated only on one-step successors, more computation can reduce performance. Test-time scaling is therefore an empirical property, not a consequence of using a JEPA.
