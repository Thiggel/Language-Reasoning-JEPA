# Model and latent states

## High-level data flow

```text
prompt and observed outcome sentences
            |
            v
token/chunk encoder -> discourse state encoder -> current state z_t

candidate intent phrase -> action encoder -> compact action code u(a)

z_t and u(a) -> JEPA predictor F -> predicted successor z_hat_(t+1,a)

current state, predicted successor, problem state -> Energy head -> E_t(a)
```

Lower Energy means the action is predicted to be better.

## Chunk encoder

Each prompt sentence, reasoning outcome sentence, or action phrase is first
represented by a token-level Transformer. The result is a fixed-width sentence
or chunk vector.

The chunk encoder is shared across prompt text, outcomes, and, in the pooled
action configuration, action phrases. This gives the model a common lexical
foundation without requiring the JEPA predictor to generate tokens.

## Discourse state encoder

The discourse state model reads:

- all encoded prompt chunks;
- the ordered sequence of observed outcome chunks;
- masks identifying real versus padded chunks.

It produces:

- `z_0`: the initial problem state after reading the prompt;
- `z_1, z_2, ...`: the state after each observed outcome.

The state before action `a_t` is `z_t`. In code this sequence is called
`prev_states`.

## Action encoder

The action encoder maps an intent phrase to a low-dimensional code `u(a)`.
The paper-facing flat experiments use a 16-dimensional action code with a
256-dimensional state.

The action code contains the stated intervention but not the numerical outcome
sentence. Consequently the predictor must infer the consequence using the
problem state and action semantics.

## JEPA predictor

The predictor implements:

```text
z_hat_(t+1,a) = F(z_t, u(a), optional history)
```

Two predictor families exist:

- **Causal Transformer predictor:** consumes an ordered history of states and
  actions. This is the intended scalable architecture.
- **Concatenation MLP predictor:** maps a state-action pair directly to a
  successor. It is retained for historical recovery and is currently the
  architecture used by the August Energy-horizon screen because that model had
  the strongest established flat JEPA result.

Run names must therefore state which predictor they use. A positive MLP result
does not automatically establish the same result for the causal Transformer.

## Online and EMA networks

JEPA training uses two copies of target-producing components:

- the **online network**, updated by gradient descent;
- the **exponential moving average network**, abbreviated EMA, updated as a
  slow average of the online parameters.

Current target copies include:

- the chunk encoder;
- the discourse state encoder;
- the JEPA predictor used by the multi-step teacher.

EMA modules are frozen, receive no gradients, and remain in evaluation mode.
Dropout is disabled in the current experiments. These choices make targets
deterministic and prevent the teacher from chasing training-time noise.

## Prediction target

For the action actually executed in the observed trace:

```text
prediction = F_online(z_t, u(a_t))
target     = z_(t+1) from the EMA encoder
```

The latent prediction loss makes the predicted successor resemble the encoded
true successor. Counterfactual state prediction applies the same principle to
alternative feasible actions whose outcomes can be generated by the training
environment.

## Transition Energy head

The current transition Energy head receives three latent vectors:

```text
E_t(a) = Head(z_t, z_hat_(t+1,a), z_0)
```

`z_0` identifies the problem and implicitly contains the question or goal. The
head does not currently receive a separate encoded goal state at deployment.
Candidate identity affects the Energy only through its predicted consequence.
This factorization is important: the head cannot simply memorize a score for
an action string without using `F(z_t, a)`.

## State Energy head

The state Energy control receives a candidate successor and initial problem
state:

```text
V(z_candidate, z_0)
```

It predicts absolute endpoint distance. At planning time a beam is scored by
the state Energy of its final imagined state.

## Direct ranker control

The direct ranker bypasses successor prediction:

```text
S_direct(z_t, z_0, u(a))
```

It receives the same history and candidate action but never constructs
`z_hat_(t+1,a)`. This tests whether predictive factorization provides anything
beyond pairwise supervised action classification.

## What “geometry” refers to

Geometry means relations among latent vectors, including:

- distances between current, successor, and goal states;
- local ordering of alternative predicted successors;
- invariance across paraphrases;
- separation when a negation or operator changes consequences;
- directions associated with task progress.

High effective rank only shows that the representation has not collapsed into
a tiny subspace. It does not show that distances or Energies rank actions
correctly.
